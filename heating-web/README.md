# КОІН · Отопление 2026/27 — веб-инструмент

Страница: `otoplenie/` (GitHub Pages). Серверная часть: `heating-web/apps-script/` (Google Apps Script).

**Что делает:**
- ввод плана и факта по ЖК (Лимнос, Атлант, Лузановский Парк, Гавайи) и месяцам;
- расчёт тарифов по методике v4: совпадает с Excel «Тарифы_отопление_методика_v4» до копейки, проверено тестом;
- отчёты: тарифы, начисление (котельная + газ, план/факт), сверхлимит нарастающим итогом, план-факт, детали;
- кошторис котельной из смет «Отопление сезон 2026/27.xlsx»;
- выгрузка в Excel и приказ с кошторисом в Word (.docx);
- вход по паролю оператора, закрытие месяцев (журнал).

## Установка (один раз)

### 1. Серверная часть в Google Apps Script (≈5 минут)

1. Откройте https://script.google.com под аккаунтом, у которого есть доступ к файлу смет, и нажмите **«Новый проект»**. Назовите его «КОІН Отопление API».
2. Удалите содержимое `Code.gs` и вставьте код из `heating-web/apps-script/Api.gs`.
3. Включите показ манифеста: **⚙ Настройки проекта → «Показывать файл манифеста appsscript.json»**. Откройте `appsscript.json` и замените его содержимое на `heating-web/apps-script/appsscript.json`.
4. Задайте пароль оператора: **⚙ Настройки проекта → «Свойства скрипта» → «Добавить свойство»**, имя `PASSWORD`, значение — пароль. В коде и на GitHub пароля нет.
5. Сохраните проект (Ctrl+S).
6. Нажмите **«Развернуть» → «Новое развертывание»**, тип **«Веб-приложение»**:
   - «Запуск от имени» — **Я**;
   - «У кого есть доступ» — **Все**.
7. Разрешите доступ: Google спросит про Таблицы и Диск. Если появится «Приложение не проверено» — «Дополнительно» → «Перейти к проекту».
8. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).

При первом входе сервер сам создаст Google-таблицу «КОІН · Отопление — данные» и заполнит план из Excel v4.

### 2. Страница на GitHub Pages

1. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
2. Выберите ветку с инструментом (`claude/lucid-fermi-h1xhm9` или `main` после слияния), папку `/ (root)`, нажмите **Save**.
3. Через 1–2 минуты страница откроется по адресу `https://elenafinance2025-star.github.io/koin-screening/otoplenie/`.

### 3. Первый вход

Откройте страницу, вставьте URL из шага 1.8 в поле «Адрес сервера» и введите пароль оператора. URL запоминается в браузере. Если прислать его разработчику, он пропишет его в `otoplenie/js/config.js`, и вводить адрес не придётся.

Затем на вкладке «Настройки» укажите ID файла «Отопление сезон 2026/27.xlsx» (часть ссылки между `/d/` и `/edit`) и на вкладке «Кошторис» нажмите «Загрузить сметы из файла».

Пароль меняется на вкладке «Настройки → Доступ» или в свойстве `PASSWORD` в Apps Script. Хранится и проверяется только на стороне Google.

## Обновления

Изменения страницы публикуются автоматически: достаточно отправить их в ветку на GitHub. Серверную часть (`Api.gs`) нужно обновлять в Apps Script только если в ней что-то менялось: **«Развернуть» → «Управление развертываниями» → карандаш → «Новая версия»**.

## Кошторис

Статьи берутся из помесячных колонок «факт» сметы ЖК по таблице соответствия: `koshtDefaultMapping()` в `otoplenie/js/koshtoris.js`, её можно править на вкладке «Настройки».

- Строки налогов (НДС, ЕН) и газ/тепловая энергия в кошторис не входят.
- Услуги, у которых в смете сумма с НДС, умножаются на 5/6.
- Налог на прибыль 1 % идёт в «Накладні». У ЛП и Гавайев он считается от газа и тепла, потому что их сметы ещё на едином налоге.
- НДС 20 % начисляется сверху.
- Тариф = смета с НДС за сезон ÷ площадь ÷ 4,5; за ноябрь начисляется 50 %.
